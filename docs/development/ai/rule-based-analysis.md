# 규칙 기반 안전 분석 파이프라인

## 목적

기존 구현은 입력이 긴급 키워드를 포함하면 `critical`, 그렇지 않으면
디지털 성범죄 고위험 결과를 반환하는 2분기 Mock이었다.

이번 파이프라인은 iOS API 계약을 유지하면서 다음 상황을 구분한다.

- 즉각적인 신체 위협
- 디지털 성범죄·촬영물 유포
- 피싱·스미싱·기관 사칭
- 온라인 계정 탈취
- 스토킹·미행
- 일반 신고·상담 정보 요청
- 충분한 신호가 없는 입력

## 처리 순서

```text
입력 정규화
→ 즉각적 신체위협 오버라이드
→ 시나리오별 표현 일치 점수화
→ 긴급도와 점수로 우선 시나리오 선택
→ 감정 상태 및 보조 의도 보강
→ 최대 3개 행동과 공식기관 반환
→ Human Review 여부 결정
```

## 안전 원칙

1. 규칙 일치값은 범죄 발생 확률이 아니다.
2. 낮은 신뢰도는 안전하다는 뜻이 아니다.
3. 즉각적인 신체위협 신호는 다른 유형보다 우선한다.
4. 행동 안내는 최대 3개로 제한한다.
5. 공식기관만 추천한다.
6. 고위험·긴급·저신뢰 결과는 Human Review 대상으로 표시한다.
7. 법률 판단이나 범죄 확정을 출력하지 않는다.

## 현재 한계

- 한국어 표현 사전 기반이며 오탈자와 은어를 모두 처리하지 못한다.
- 문맥, 부정 표현, 풍자와 인용을 완전히 이해하지 못한다.
- confidence는 규칙 일치 강도이며 통계적 범죄 가능성이 아니다.
- 실제 AI 모델 또는 전문가 판단을 대체하지 않는다.

## 후속 개발

- Human Review 대시보드 연계
