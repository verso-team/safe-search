# 클릭베이트 기준선 모델 카드

## 목적

한국어 뉴스 제목에서 과장, 호기심 자극, 즉각적인 클릭 유도 표현을 찾아
`normal`, `suspicious`, `clickbait`으로 분류하는 재현 가능한 기준선입니다.
향후 SK A.X 또는 학습 모델의 개선 효과를 비교하는 기준으로 사용합니다.

## 버전

- 정책: `clickbait-policy-2026.07.30-v2`
- 모델: `safe-search-rules-v1`
- 의심 임계값: `0.28`
- 클릭베이트 임계값: `0.45`

## 입력과 개인정보

- 입력: 제목, 선택적 본문, 선택적 출처 URL
- 원문은 기본적으로 서버에 저장하지 않습니다.
- 같은 입력인지 확인할 수 있도록 SHA-256 해시와 16자리 추적 ID만 반환합니다.

## 출력

- 분류와 위험 점수
- 분석 신뢰도
- 입력에서 발견한 근거 문구와 가중치
- 정책·모델 버전
- 입력 SHA-256 및 추적 ID
- 인간 검토 필요 여부와 사유
- 폴백 사용 여부와 모델 한계

## 인간 검토 조건

- 점수가 `0.23` 이상 `0.49` 이하인 경계 사례
- 제목과 본문을 합친 문맥이 20자 미만인 사례
- 모델이 명시적으로 불확실하다고 판단한 사례

## 폴백

`CLICKBAIT_MODEL_PROVIDER=ollama` 설정에서 로컬 모델 연결이나 구조화 응답
검증에 실패하면 규칙 기준선으로 자동 전환합니다. 이 경우
`fallback_used=true`와 실패 사실을 한계 항목에 기록합니다.

## 알려진 한계

- 기사 내용의 사실 여부를 판정하지 않습니다.
- 풍자, 인용, 유행어와 분야별 표현에서 오탐이 발생할 수 있습니다.
- 현재 시드 데이터는 12건의 기능 검증용이며 일반 성능을 대표하지 않습니다.
- 실제 성능 주장을 위해 독립 라벨러, 데이터 출처, 분할 기준이 필요합니다.

## Evidence

`data/evaluation/baseline-evidence.json`에는 데이터 해시, 개별 예측, 근거,
혼동 항목과 인간 검토율이 포함됩니다. 평가 스크립트로 재생성할 수 있습니다.
