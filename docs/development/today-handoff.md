# 오늘 개발 인계

## 오늘 완료 범위

- 클릭베이트 분석 API 계약
- 규칙 기반 재현 가능한 기준선 모델
- Ollama 선택 연결과 실패 시 안전한 폴백
- 분석 근거, 추적 ID, 한계, 인간 검토 조건 반환
- API 자동 테스트
- 나섬이 기반 반응형 프로토타입

## 최소 역할 배분

### 이영준

- 개발 통합과 API·UI 연결
- Evidence 및 제출 문서 취합

### 정한빈

- API 실행 화면 캡처 2장
- 개인정보·로그 보존 기준 초안

### 임준호

- 클릭베이트 데이터 20건 샘플 정리
- 오탐·미탐 사례와 임계값 검토

### 김은솔

- 최종 홈 화면 1종만 확인
- 색상 또는 가독성 수정 의견을 최대 3개까지 전달

김은솔에게 신규 화면 제작, 코드 수정, 디자인 시스템 문서, 발표자료 편집,
다이어그램 제작은 요청하지 않습니다.

## 다음 실행 순서

1. SK A.X 사용 조건을 운영진 안내와 대조합니다.
2. 샘플 데이터로 규칙 기준선의 오탐·미탐을 기록합니다.
3. 프런트엔드 입력을 클릭베이트 제목·본문 형식으로 연결합니다.
4. 모델별 결과를 같은 Evidence 형식으로 저장합니다.
5. 경계 사례는 자동으로 인간 검토 대상으로 보냅니다.

## 로컬 AI 설정

기본 실행은 외부 모델 없이 규칙 기준선을 사용합니다.

```env
CLICKBAIT_MODEL_PROVIDER=heuristic
```

Ollama를 사용할 때만 아래와 같이 변경합니다.

```env
CLICKBAIT_MODEL_PROVIDER=ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:8b
```

Ollama가 꺼져 있거나 JSON 검증에 실패하면 규칙 기준선으로 자동 복귀합니다.
