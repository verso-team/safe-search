# Branch Guide

## Permanent branches

- `main`: final, stable, presentation-ready
- `develop`: integration branch

## Initial working branches

- `feature/frontend`
- `feature/backend`
- `feature/ai-model`
- `feature/scenario`
- `feature/admin`
- `feature/design`
- `docs/professor-materials`

## Recommended flow

```text
Issue 생성
→ develop에서 브랜치 생성
→ 작업 및 커밋
→ Pull Request
→ 리뷰
→ develop 병합
→ 통합 검증
→ main 병합
```
