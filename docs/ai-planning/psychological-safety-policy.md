# SAFE:SEARCH Psychological Safety Policy v0.1

## 목적

SAFE:SEARCH는 디지털 범죄 피해 상황의 사용자를 지원하지만,
AI가 사용자의 감정을 진단하거나 피해자의 행동을 대신 결정하는 시스템을 목표로 하지 않는다.

이 정책은 AI 응답이 피해자의 불안과 압박을 불필요하게 증가시키지 않도록
응답 방식, 표현 제한, 사용자 선택권, 평가 방법을 정의한다.


## 근거 1. 사용자 테스트 관련 연구 요약

팀이 정리한 연구 자료에서는 실제 피해자 대상 평가가 어려운 경우
촬영물 이용 성폭력 피해 상황을 가정한 시나리오를 사용하였다.

참여자는 피해자의 입장에서 다음 7개 과제를 수행한다.

1. 지원기관 확인
2. 신고 이후 보복 우려 대응 확인
3. 불법 촬영물 유포 협박 대응 확인
4. 유사 피해 사례 탐색
5. 고소장 작성 방법과 양식 확인
6. 수사·재판 과정의 피해자 권리 확인
7. 피해자를 위로하고 지지하는 정보 확인

정보 품질 평가는 AIMQ를 사용하며 다음 13개 특성을 다룬다.

- 접근성
- 양
- 신뢰성
- 범위
- 간결성
- 형식
- 검색 용이성
- 정확성
- 해석 용이성
- 객관성
- 유용성
- 시의성
- 이해 용이성

정서적 지지는 SRS를 사용하며 피해자 비난 방지,
피해자 이해, 판단하지 않는 태도, 진정성, 감정 이해 등의 항목을 평가한다.

팀 연구 요약에서는 챗봇 정보가 인터넷 검색 대비
13개 정보 항목 중 11개에서 우위로 정리되었으나
신뢰성과 객관성은 상대적으로 부족한 것으로 정리되었다.

이에 SAFE:SEARCH는 단순한 생성형 답변보다
공식기관 정보 우선, 출처 확인, 위험 결과 탐지를 핵심 설계로 사용한다.


## 근거 2. 심리상담 전문가 자문 메모

2026년 8월 팀 내부 전문가 자문에서 다음 사항을 반영하였다.

### 당위적 표현 제한

피해자에게 특정 행동을 재촉하거나 강압적으로 요구하지 않는다.

가능한 경우 이용자에게 여러 정보를 직접 검색하도록 요구하기보다
확인된 공식기관 접근 경로를 바로 제시한다.


### 감정 추론의 한계

같은 표현도 상황과 맥락에 따라 의미가 달라질 수 있으므로
AI가 짧은 문장만으로 사용자의 심리상태를 확정하지 않는다.

AI의 감정상태 추론값은 응답 생성에 참고할 수 있으나
사실이나 임상적 판단으로 표현하지 않는다.


### 피해자 반응의 다양성

피해자가 항상 불안, 공포, 슬픔을 직접 표현한다고 가정하지 않는다.

덤덤한 표현, 감정 억압, 사건을 타인의 일처럼 이야기하는 반응 등
다양한 표현 가능성을 고려한다.


### 말투

기본값은 부드럽고 정중한 존댓말을 사용한다.

권위적으로 느껴질 수 있는 극존칭은 기본값으로 사용하지 않는다.

반말 또는 보다 편한 말투는 사용자가 명시적으로 선택한 경우에만 제공한다.


### 정보 우선과 대화 우선

모든 사용자에게 공감을 먼저 제시하거나
모든 사용자에게 정보부터 제공하지 않는다.

사용자가 명확하게 필요한 정보를 요청한 경우 정보 우선,
정서적 지지를 명시적으로 원하는 경우 대화 우선을 사용할 수 있다.

의도가 불명확하면 두 방식을 제시하고 사용자가 선택하게 한다.


## 구현 정책

PSY-01
사용자의 감정을 사실처럼 단정하지 않는다.

PSY-02
피해자의 행동에 책임을 돌리거나 비난하지 않는다.

PSY-03
안전하거나 문제가 해결될 것이라고 근거 없이 보장하지 않는다.

PSY-04
신고, 상담, 기관 연결 등을 명령형으로 강제하지 않는다.

PSY-05
피해자에게 기관과 대응방법을 다시 직접 검색하도록 떠넘기지 않는다.

PSY-06
기본 말투는 soft_polite로 한다.

PSY-07
사용자가 명시적으로 원하는 경우 casual 말투를 선택할 수 있다.

PSY-08
의도가 불명확한 경우 information_first 또는 support_first를 AI가 임의로 확정하지 않고 user_choice를 사용한다.


## 응답 모드

information_first

필요한 대응 정보와 공식기관 정보를 먼저 제공한다.

support_first

감정을 추측하지 않으면서 사용자가 상황을 이야기하고 정리할 수 있도록 한다.

user_choice

정보를 먼저 확인할지,
이야기하면서 상황을 정리할지 사용자가 선택한다.


## Psychological Safety Audit v0.1

초기 구현은 설명 가능한 lexical guardrail을 사용한다.

탐지 대상:

- coercive_language
- emotion_assumption
- over_reassurance
- victim_blaming
- overly_authoritative_tone
- search_burden

이 규칙은 최종적인 심리 판단 모델이 아니다.

문맥에 따라 오탐과 미탐이 존재할 수 있으므로
향후 실제 사용자 입력과 AI 응답을 함께 보는 문맥 기반 평가가 필요하다.


## 사용자 평가 계획

초기 평가는 실제 피해자 데이터를 직접 사용하지 않고
가상의 피해 시나리오와 합성 입력을 중심으로 수행한다.

정보 제공 품질:
AIMQ 기반 평가

정서적 지지:
SRS 기반 평가

제품 평가에서는 다음을 함께 확인한다.

- 정보 접근성
- 정보 신뢰성
- 정보 객관성
- 정보 간결성
- 이해 용이성
- 피해자 비난 여부
- 비판단적 표현
- 감정 단정 여부
- 사용자 선택권
- 공식기관 연결 가능성


## 개인정보 및 자문 기록

공개 저장소에는 자문자의 개인 식별정보나
불필요한 소속·경력 정보를 기록하지 않는다.

자문자의 이름과 소속을 공식 Evidence에 사용할 경우
팀에서 공개 가능 여부를 별도로 확인한다.


## 현재 한계

- v0.1은 키워드 기반 표현 점검이다.
- 피해자의 실제 감정상태를 판단하지 않는다.
- AIMQ/SRS 사용자 평가는 아직 수행되지 않았다.
- 심리상담 전문가 자문은 제품 설계 참고자료이며 임상 검증을 의미하지 않는다.
- 실제 서비스 적용 전 사용자 테스트와 추가 전문가 검토가 필요하다.
